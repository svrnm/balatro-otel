# Scoring signal reference

Generated by Weaver v0.28.0 from `telemetry/registry`. Edit the registry and template, then regenerate.
For interpretation, scope, and limitations see [scoring telemetry](scoring-telemetry-design.md).

## Span: `balatro.card.evaluate`

Evaluation of one card or joker in one scoring context. Only recorded when the evaluation produced an effect or took longer than 1 ms.

| Attribute | Meaning |
| --- | --- |
| `balatro.card.area` | Where the card sits. |
| `balatro.card.debuffed` | Whether the card is debuffed at evaluation entry. |
| `balatro.card.edition` | Edition key, with vanilla boolean flags normalized to e_ keys; omitted when absent. |
| `balatro.card.effect` | Numeric effects returned by a card evaluation, `<key>` being "<source>.<effect>". |
| `balatro.card.enhancement` | Center key when the card belongs to the Enhanced set; omitted otherwise. |
| `balatro.card.evaluation.context` | Comma-separated scoring context flags the card was evaluated in. |
| `balatro.card.evaluation.copy` | Whether blueprint or blueprint_card is set in the engine context. |
| `balatro.card.evaluation.copy_source.id` | Live copier ID from the blueprint helper argument on copy events, or context.blueprint_card on other observations, when provided. |
| `balatro.card.evaluation.has_effects` | Whether the primary evaluation result is a nonempty table; not proof of application. |
| `balatro.card.evaluation.has_post_effects` | Whether the post evaluation result is a nonempty table. |
| `balatro.card.evaluation.retrigger` | Whether the engine context identifies an actual Joker retrigger execution. |
| `balatro.card.evaluation.retrigger_source.id` | Live card ID from a card-valued context.retrigger_joker. |
| `balatro.card.instance.id` | Session-local identity of a live card object; not stable across reloads. |
| `balatro.card.key` | Internal key of the card's center. |
| `balatro.card.name` | Display name of a card; "<rank> of <suit>" for playing cards. |
| `balatro.card.post_effect` | Numeric fields in post results, using <index>.<source>.<effect> paths for ordered result lists, or <source>.<effect> for a direct result table. |
| `balatro.card.rank` | Base rank at evaluation entry, not effective scoring rank. |
| `balatro.card.seal` | Seal name at evaluation entry; omitted when absent. |
| `balatro.card.set` | Card set. |
| `balatro.card.suit` | Base suit at evaluation entry, not effective scoring suit. |
| `balatro.run.seed` | Seed of the current run; set on every span and log record started during a run. |
| `session.id` | A unique ID to identify a session. |

## Event: `balatro.effect`

An effect handler was invoked during synchronous hand scoring; outcome and before/after state describe observed handling, not causal impact.

| Attribute | Meaning |
| --- | --- |
| `balatro.effect.amount` | Amount of the scoring effect. |
| `balatro.effect.attribution` | Evidence for the legacy source display name; only explicit attribution establishes a source identity. |
| `balatro.effect.component` | Component identified by the effect-table application path, not inferred from card properties. |
| `balatro.effect.from_edition` | Whether the caller marked this handler invocation as originating from an edition. |
| `balatro.effect.key` | Kind of scoring effect applied. |
| `balatro.effect.outcome` | Handler return classification: true/string/table is handled, false is unhandled, otherwise unknown; not proof of score mutation. |
| `balatro.effect.parent_sequence` | Enclosing effect handler sequence for nested calls; omit for outermost calls. |
| `balatro.effect.sequence` | Effect handler entry order within one synchronous hand scoring operation. |
| `balatro.effect.source` | Legacy source display name, from effect.card or falling back to the scored target; see balatro.effect.attribution for evidence. |
| `balatro.effect.source_card.instance.id` | Live source card ID, only when effect.card explicitly identifies a source. |
| `balatro.effect.source_card.key` | Center key of the explicitly identified source card. |
| `balatro.effect.target.instance.id` | Live target card ID from the scored_card argument. |
| `balatro.effect.target.key` | Center key of the target card. |
| `balatro.effect.target.name` | Display name of the target card. |
| `balatro.score.before.chips` | Running chips immediately before the handler; outer calls include nested mutations. |
| `balatro.score.before.mult` | Running mult immediately before the handler; outer calls include nested mutations. |
| `balatro.score.chips` | Running chips while a hand is being scored. |
| `balatro.score.mult` | Running mult while a hand is being scored. |
